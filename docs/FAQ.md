## 关于产品

### AA4C 和 LocalSend / Syncthing / Motrix 有什么区别？

它们各自只解决一件事，AA4C 把这几件事放在**同一套设备身份和同一个应用**里：传完的文件可以直接进同步范围，下载完的文件可以自动归档再同步到 NAS，中间不用换软件、不用重复配对。

另外几个具体差别：

- 同步默认**只同步文件名，不同步内容**（内容点了才拉），所以小硬盘设备也能"拥有"一个大素材库
- 配对之后信任还分四级，**配对 ≠ 交出所有文件**
- 跨网络用的信令 / 中继**只支持自建**，没有官方节点

### 需要注册账号吗？要联网吗？

不需要账号。**远程连接默认关闭**，关着的时候 AA4C 只在局域网活动，不会向互联网发起任何连接。没有遥测、没有崩溃上报、没有"匿名统计"。

### 免费吗？以后会收费吗？

Apache-2.0 开源，代码全部公开。你随时可以自己从源码构建。

### 我的文件会经过你们的服务器吗？

不会——AA4C **没有服务器**。局域网内是设备直连；跨网络时如果打洞失败需要中继，中继服务器也是**你自己部署**的，而且它只看得到密文和端点映射，看不到文件内容。

### 支持 iOS 吗？

暂时没有。Android 有实验版 APK，iOS / iPad 在规划中（[ROADMAP.md](../ROADMAP.md)）。

### 有 NAS / Docker 版本吗？

`aa4c-server`（信令 + 中继）提供 Linux x86_64 二进制，可以跑在 NAS 或 VPS 上，见 [自建服务器指南](SELF_HOSTING.md)。带完整 UI 的 NAS 版本是 V1.0 的目标。

## 找不到设备

这是最常见的问题，按顺序排查：

### 1. 两台设备在同一个网络吗？

必须在**同一个局域网 / 同一个 WiFi**。注意这些坑：

- 有些路由器的 **2.4G 和 5G 是两个隔离的网络**
- **访客网络（Guest WiFi）**通常与主网络隔离
- 手机开着 **VPN / 代理**时，局域网流量可能被劫持——先关掉试试
- 电脑接的是**有线**、手机连的是 WiFi，但两者不在同一网段

### 2. 防火墙放行了吗？

AA4C 用 **TCP 42420**（传输）和 **UDP 5353**（mDNS 设备发现）：

| 系统 | 处理方式 |
|------|----------|
| Windows | 首次运行的防火墙弹窗必须勾选 **「专用网络」**。误点了取消就到「Windows Defender 防火墙 → 允许应用通过防火墙」里找到 AA4C，勾上「专用」 |
| macOS | 首次运行弹「是否允许接受传入连接」，点**允许**。之后可在「系统设置 → 网络 → 防火墙 → 选项」里确认 |
| Linux（ufw） | `sudo ufw allow 42420/tcp && sudo ufw allow 5353/udp` |

### 3. 网络本身屏蔽了组播吗？

设备发现依赖 mDNS 组播。以下网络环境经常发现不到设备，**且不是 AA4C 能解决的**：

- 公司 / 学校网络（常开启「客户端隔离 / AP Isolation」）
- 咖啡厅、机场等公共 WiFi
- 一些运营商光猫的默认配置

**验证办法**：用手机开个热点，两台设备都连上去试试。如果热点下能发现，就是原网络限制了组播。

### 4. Android 上发现不到

Android 的 mDNS 需要 `MulticastLock`，AA4C 启动时会申请。如果仍然不行：

- 确认给了 App 本地网络 / 位置相关权限（部分 ROM 把 WiFi 扫描权限与位置绑定）
- 部分国产 ROM 的省电策略会在后台冻结 App，把 AA4C 加进「不受限制 / 允许后台运行」白名单

### 5. 还是不行

关掉两端 AA4C 重开一次（会重新广播）。仍然不行请带上系统、网络环境、防火墙状态开 [Issue](https://github.com/HuoTaoCN/AA4C/issues)。

## 配对问题

### 两台设备显示的 6 位数字不一样

**不要点确认，点拒绝。**

这 6 位数字由两台设备**各自独立计算**得出，从不经过网络。正常情况下必然一致。不一致意味着两种可能：

1. 你们点的不是同一次配对（比如同时发起了多个配对，串了）——都取消，重来一次
2. 有中间人在攻击这次配对——换一个可信网络再试

### 配对了，但对方看不到我的同步文件

配对默认落在**「朋友」**级别，朋友不参与跨设备索引。到「设置 → 已配对设备」把对方升级为**完全信任**（前提是那确实是你自己的设备）。

### 怎么取消配对？

「设置 → 已配对设备 → 解除配对」。对方立刻失去连接你的权限。

## 传输问题

### 传输中断了，要从头再来吗？

不用。AA4C 支持**断点续传**，重连后从断点继续。

### 传完提示校验失败

每个文件传完都会做 BLAKE3 哈希校验，不一致会自动重传。持续失败通常说明链路不稳定（弱 WiFi、网线接触不良），换个网络试试。

### 对方一直没收到确认弹窗

- 对方 App 可能在后台被系统挂起（尤其是手机），让对方切到前台
- 对方如果开了「信任设备来的文件自动接收」，那是直接开始接收，本来就没有弹窗

### 文件收到哪去了？

「设置 → 接收文件保存到」，默认 `~/Downloads/AA4C`。

### 能传多大的文件？

没有人为限制。文件夹会保持目录结构完整送达。

## 同步问题

### 文件显示 🟡「可下载」是什么意思？

意思是**文件名在索引里，但内容还没在本机**。这是 AA4C 的设计：默认只同步文件名和目录结构，内容点了才拉。点一下那个文件就会取回本机，取完变 🟢。

### 文件显示 🔴「设备离线」

只有当前离线的设备上有这个文件的内容。等那台设备上线即可。

### 同步文件夹加了，对方却看不到

检查三件事：

1. 对方是不是**完全信任**级别？朋友级不参与索引
2. 两台设备当前是否都在线、能互相发现？
3. 点一下「刷新设备」重新交换索引

### 出现「多版本」是怎么回事？

两台设备上有同名但内容不同的文件。AA4C **不会替你选一个覆盖另一个**——各版本按序号并列显示，你分别取回后自己决定留哪个。

### 我删掉本地文件，别的设备也会被删吗？

同步的是索引状态。请注意：把重要文件放进同步范围之前，先在小范围试一下你期望的行为，重要数据始终应该另有备份。

## 分享与远程连接

### 分享链接对方打不开

- **同一局域网**：应该直接可用，检查两端是否都在线
- **跨网络**：双方都需要在「设置」里配置**自建服务器地址**并**打开远程连接**开关。AA4C 没有官方公共服务器，见 [自建服务器指南](SELF_HOSTING.md)

### 生成分享时下拉框是空的

只能分享**已在同步文件夹里的文件**。先去「同步」页添加一个同步文件夹。

### 分享出去还能收回吗？

能。「我的分享」里点撤销，链接立刻失效。也可以在生成时就设 1 小时 / 1 天 / 7 天的有效期。

### 分享会让对方变成我的信任设备吗？

不会。分享和配对是两件独立的事，分享只对那**一个文件**有效。

### 为什么不提供官方中继服务器？

这是有意的产品决策：官方服务器意味着单点故障、运营成本，以及"有一天被要求交出数据"的风险。AA4C 选择让基础设施**完全由用户掌握**。

## 下载问题

### 支持哪些链接？

HTTP / HTTPS / FTP 直链，以及 BT / 磁力链接（`magnet:?xt=urn:btih:…`）。粘贴时**一行一个可以批量添加**。

### 磁力链接一直是 0，连不上

磁力下载依赖 DHT 和 tracker，慢或者连不上通常是资源本身没有活跃做种者，或网络限制了 BT 流量。可以：

- 换一个种子多的资源试试
- 检查是否有网络环境（校园网、公司网）屏蔽了 BT

### 改了限速 / 并发数没生效

下载设置**需要重启应用后生效**——它们写进引擎启动时生成的配置文件，AA4C 不做热更新。

### 下载速度比其他下载器慢

调大「设置 → 下载 → 单文件最大连接数」（分段下载，1–16）。不过很多服务器本身就限制单 IP 的连接数和速度。

### 下载完的文件为什么没有自动归档？

需要**两个条件同时满足**：

1. 「设置 → 归档 → 下载完成后自动归档」开着（默认开）
2. **至少启用了一条归档规则**（规则默认全部停用）

这是有意的保守设计——自动移动文件必须由你明确授权。

### 下载引擎崩了怎么办？

直链引擎（aria2）崩溃时 AA4C 会自动重连、必要时完整重新拉起子进程，通常不需要你干预。如果连重新拉起也失败，本次会话内下载会不可用——**重启应用**即可恢复。

### 下载内容的责任

AA4C 只是下载工具，不提供、不索引、不推荐任何资源。请遵守所在地区法律，只下载你有权下载的内容。

## AI 与知识库

### AI 功能显示不可用

需要你自己准备 GGUF 模型文件：

1. 从 Hugging Face 等处下载 GGUF 模型（AA4C 不代为分发模型）
2. 放进「设置 → AI → 模型文件目录」
3. 在设置里选定**对话模型**；知识库检索还需要选一个**嵌入模型**

### 会把我的文件传到云上分析吗？

**不会。** AI 完全跑在本机的 `llama-server` 上，零云端调用，断网也能用。代码里没有任何第三方 AI 服务的端点。

### AI 会自动移动我的文件吗？

**不会。** 这是硬性设计边界：只有确定性规则可以自动移动文件；**AI 的输出永远只进"待确认"队列**，你点「采纳」它才生效。AI 猜错的最坏后果只是一条你忽略掉的建议。

### AI 很占内存

引擎是**懒启动 + 空闲自停**：用到才起，默认空闲 10 分钟后自动退出释放内存（可在「设置 → AI」调整）。也可以选更小的模型（如 4B 的 Q4 量化）。

### 归档移错了怎么办？

「归档 → 最近动作」里每条都能**一键撤销**，文件回到原来的位置。

### 知识库回答不准

- 检查是否配了合适的嵌入模型
- 更大的对话模型通常回答更好
- 答案带**原文引用**，可以点开核实来源

## 隐私与安全

### AA4C 会收集什么数据？

**什么都不收集。** 没有遥测、没有崩溃上报、没有匿名统计、没有账号。代码里搜不到任何分析 SDK 或第三方端点——这一条你可以自己在仓库里验证。

### 传输是加密的吗？能关掉吗？

全程 TLS 1.3 + 证书固定加密，**且没有关闭开关**。项目规则明令禁止引入"关闭加密/校验"的配置项。

### 我的私钥在哪里？

本地文件，权限 0600。**永不写入数据库、永不写入日志、永不离开设备。**

### 本地跑的引擎会不会被局域网里的人连上？

不会。aria2 / Transmission / llama-server 一律绑定 `127.0.0.1`（回环），并且用**每次启动重新生成的随机密钥**做认证，局域网上的其他机器连不到。

### 卸载后我的数据还在吗？

在。收到的文件、下载的文件、归档的文件都是普通文件，放在你指定的目录里，没有专有格式、没有加密封装。

### 发现安全漏洞怎么报告？

**请不要开公开 Issue。** 按 [SECURITY.md](../SECURITY.md) 的流程私下报告（GitHub Security Advisory 或 security@aa4c.com）。

## 安装与平台

### macOS 提示"无法打开，因为无法验证开发者"

安装包**未做苹果签名**（签名需要付费开发者账号）。绕过方式：右键点应用图标 →「打开」→ 再点「打开」。或到「系统设置 → 隐私与安全性」点「仍要打开」。

介意的话可以自己从源码构建，构建脚本都在仓库里。

### Windows 提示"Windows 已保护你的电脑"

同样是未做代码签名。点「更多信息」→「仍要运行」。

### Linux 上 AppImage 跑不起来

先 `chmod +x AA4C*.AppImage`。如果提示缺少 FUSE，可以装 `libfuse2`，或者改用 `.deb` / `.rpm` 包。

### Android 版能用哪些功能？

实验版，主要覆盖**传输**和**同步**。下载中心与 AI 归档目前仅桌面三平台。

### 支持哪些系统版本？

桌面端基于 Tauri 2，系统要求跟随 Tauri 2 的[官方支持范围](https://tauri.app/start/prerequisites/)（Windows 10/11、近几年的 macOS、主流 Linux 发行版）。Android 为实验版。

如果你的系统偏旧，最可靠的判断办法是直接装一下试试——装不上或起不来，欢迎带上系统版本开 [Issue](https://github.com/HuoTaoCN/AA4C/issues)。
